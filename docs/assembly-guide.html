Snack Express · Stage 2 — Wired Drive

탱크 차량 조립 가이드

TP101 섀시 + TB6612 모터 드라이버 + CoreS3 — 전자공학 처음인 개발자를 위한 설명

00딱 3개념만 알면 됩니다

TB6612 = 모터 전용 백엔드 프록시. CoreS3의 GPIO는 3.3V짜리 아주 약한 신호만 냅니다 — 모터를 직접 돌리면 보드가 타요. 그래서 중간에 TB6612를 둡니다. CoreS3는 "왼쪽 모터 70% 전진"이라는 명령(신호)만 보내고, 실제 파워(배터리 7.4V)는 TB6612가 모터에 꽂아줍니다. 프론트엔드가 DB에 직접 붙지 않고 API 서버를 거치는 구조와 같아요 — 권한(전력) 분리입니다.
GND 공통 = 타임존 맞추기. "3.3V"라는 건 절대값이 아니라 어떤 기준점(0V)보다 3.3V 높다는 뜻입니다. 배터리 회로와 CoreS3 회로가 서로 다른 0V 기준을 쓰면, 같은 신호를 서로 다르게 읽어요 — 타임존 안 맞춘 서버 두 대가 타임스탬프 비교하는 꼴. 그래서 두 회로의 GND(0V 기준선)만 한 가닥으로 이어줍니다. 전원(+)은 절대 섞지 않고, 기준선만 공유하는 거예요.
PWM = 스로틀링으로 속도 조절. GPIO는 ON/OFF밖에 못 합니다. 그런데 초당 수천 번 껐다 켰다 하면서 켜져 있는 시간의 비율(듀티비)을 조절하면 모터 입장에선 "평균 70% 파워"가 돼요. 요청을 70%만 통과시키는 rate limiter라고 생각하면 됩니다. 우리 프로토콜의 drive.left: 0.7이 펌웨어에서 이 듀티비로 변환됩니다.

01부품 역할표

TP101 탱크 섀시몸체 + 기어모터 2개(좌/우 트랙). 모터는 각각 선 2가닥 — 전류 방향이 바뀌면 회전 방향도 바뀝니다.
TB6612FNG ×2 (1개만 사용)모터 드라이버. 1개가 모터 2채널(A·B)을 담당하므로 이번엔 1개면 충분, 나머지는 예비.
18650 ×2 + 홀더모터 전용 전원. 직렬 7.4V. CoreS3엔 절대 연결하지 않습니다.
M5Stack CoreS3두뇌(이자 조종실 서버의 씬 클라이언트). Grove 포트에서 신호 4가닥 + 3.3V + GND를 냅니다.

안전 수칙 (한 번만 읽어주세요)

① 배선 작업은 항상 배터리를 홀더에서 뺀 상태로. 전원 연결은 맨 마지막.
② 18650 3개 직렬 금지 — 12.6V는 TB6612 상한(13.5V)에 너무 붙어서 위험.
③ 빨간 선(7.4V)이 CoreS3 어디에도 닿으면 안 됩니다. 보드 즉사 코스.
④ 첫 테스트는 반드시 차체 뒤집어 바퀴를 공중에 띄우고 — 데드맨이 검증되기 전까지 바닥 주행 금지.

03조립 순서

  1. 벤치 준비

    TP101을 뒤집어 바퀴를 공중에 띄웁니다. 배터리는 홀더에서 빼둡니다.

  2. TB6612 로직 묶음 배선

    VCC·STBY·PWMA·PWMB 네 핀을 전부 CoreS3 3V3에 묶습니다.

    왜? STBY(standby)가 LOW면 칩이 잠들고, PWMA/PWMB가 LOW면 출력이 차단돼요. 넷 다 HIGH 고정 = "칩 항상 깨움 + 출력 항상 허용". 속도는 AIN/BIN 핀의 PWM으로만 조절하는 단순화 전략입니다.

  3. 신호선 4가닥

    G2→AIN1, G1→AIN2 (왼쪽) / G8→BIN1, G9→BIN2 (오른쪽). Grove 케이블을 잘라 쓰면 커넥터 그대로 활용 가능해요.

  4. GND 공통

    CoreS3 GND ↔ TB6612 GND를 한 가닥으로 연결합니다. 이게 두 회로가 섞이는 유일한 지점.

  5. 모터 연결

    왼쪽 모터 두 가닥 → A01/A02, 오른쪽 → B01/B02. 극성은 아직 신경 쓰지 마세요 — 돌려보고 반대면 두 선을 맞바꾸면 끝.

  6. 배터리 연결 (마지막!)

    배선을 눈으로 한 번 더 점검 → 배터리 ＋ → VM, − → GND. 홀더에 18650 장착.

  7. 드라이브 테스트

    drive 펌웨어가 올라간 뒤: 대시보드 WASD 패드 → 바퀴가 공중에서 도는지, 버튼을 떼면 300ms 안에 멈추는지(데드맨) 확인. 이게 통과해야 바닥 주행 허가입니다.

04전원 켜기 전 체크리스트

  • 빨간 선(7.4V)이 VM 외엔 아무 데도 안 닿는다
  • VCC·STBY·PWMA·PWMB 전부 3.3V에 묶였다
  • CoreS3 GND ↔ TB6612 GND 연결됐다 (공통 기준선)
  • 바퀴가 공중에 떠 있다
  • 18650이 2개다 (3개 아님)

Snack Express · Stage 3 — Independent Vehicle

탱크 차량 조립 가이드

TP101 섀시 + TB6612 모터 드라이버 + ESP32-C3 (차량 독립 두뇌) — 전자공학 처음인 개발자를 위한 설명

v2 변경: 차량 두뇌를 CoreS3 유선(2단계)에서 ESP32-C3 탑재(3단계)로 전환. CoreS3(스타키)는 차량과 전선 연결 없이 콕핏에 앉기만 하고, 차량은 자체로 조종실 서버에 접속합니다.

00딱 3개념만 알면 됩니다

TB6612 = 모터 전용 백엔드 프록시. ESP32-C3의 GPIO는 3.3V짜리 아주 약한 신호만 냅니다 — 모터를 직접 돌리면 보드가 타요. 그래서 중간에 TB6612를 둡니다. C3는 "왼쪽 모터 70% 전진"이라는 명령(신호)만 보내고, 실제 파워(배터리 7.4V)는 TB6612가 모터에 꽂아줍니다. 프론트엔드가 DB에 직접 붙지 않고 API 서버를 거치는 구조와 같아요 — 권한(전력) 분리입니다.
GND 공통 = 타임존 맞추기. "3.3V"라는 건 절대값이 아니라 어떤 기준점(0V)보다 3.3V 높다는 뜻입니다. 배터리 회로와 C3 회로가 서로 다른 0V 기준을 쓰면, 같은 신호를 서로 다르게 읽어요 — 타임존 안 맞춘 서버 두 대가 타임스탬프 비교하는 꼴. 그래서 두 회로의 GND(0V 기준선)만 한 가닥으로 이어줍니다. 전원(+)은 절대 섞지 않고, 기준선만 공유하는 거예요.
PWM = 스로틀링으로 속도 조절. GPIO는 ON/OFF밖에 못 합니다. 그런데 초당 수천 번 껐다 켰다 하면서 켜져 있는 시간의 비율(듀티비)을 조절하면 모터 입장에선 "평균 70% 파워"가 돼요. 요청을 70%만 통과시키는 rate limiter라고 생각하면 됩니다. 우리 프로토콜의 drive.left: 0.7이 펌웨어에서 이 듀티비로 변환됩니다.

01부품 역할표

TP101 탱크 섀시몸체 + 기어모터 2개(좌/우 트랙). 모터는 각각 선 2가닥 — 전류 방향이 바뀌면 회전 방향도 바뀝니다.
TB6612FNG ×2 (1개만 사용)모터 드라이버. 1개가 모터 2채널(A·B)을 담당하므로 이번엔 1개면 충분, 나머지는 예비.
18650 ×2 + 홀더모터 전용 전원. 직렬 7.4V(완충 8.4V). C3에 직결 절대 금지.
ESP32-C3 슈퍼미니차량의 두뇌. Wi-Fi로 조종실 서버에 직접 접속해 drive 명령을 받습니다. CoreS3(스타키)는 차량과 전선 연결 없음 — 콕핏에 앉기만.
브레드보드 (빵판)무납땜 조립판 — 칩·전원·모터까지 전부 이 위에서 최종 탑재. 빨강 레일=3.3V, 파랑 레일=GND. 접점 한계 ~1A라 트랙이 끼인 채 버티는 스톨 상황만 피할 것.
벅 컨버터 SD-0516 (구매 완료)C3는 5V/3.3V만 먹습니다(7.4V 직결 시 즉사). 고정 5V 출력·연속 1.6A — 조정 작업 불필요. IN+에 배터리 ＋, OUT+를 C3 5V 핀에. 입력 하한 7V: 팩 전압이 7.2V쯤 되면 충전 타이밍입니다.

02기계 조립 — 상자에서 책상까지

배선(전선 연결)은 맨 마지막입니다. 그 전에 몸체부터 만들어요. 준비물: 소형 십자드라이버 · 가위 · 마스킹테이프 · 케이블타이. 그리고 18650 배터리는 멀리 치워두세요 — 마지막 단계 전까지 등장하지 않습니다.

  1. 부품 4무더기 분류

    ① TP101 상자 ② TB6612 봉지 ③ 18650+홀더 ④ ESP32-C3+점퍼선. 섞이면 나사 찾느라 시간 다 갑니다.

  2. TP101 섀시 조립 (동봉 설명서 + 아래 포인트)

    모터 2개를 섀시 안쪽에 나사 고정 — 이때 모터 전선 2가닥이 섀시 윗면(TB6612 둘 곳) 쪽으로 나오게 방향을 잡으세요. 전선이 짧아서 방향이 틀리면 다시 풀게 됩니다. 이어서 구동 스프로킷을 모터 축에, 보조 바퀴를 섀시에, 마지막으로 트랙을 겁니다.

    ✅ 체크: 손으로 트랙을 굴려 양쪽 다 부드럽게 도는지. 뻑뻑하면 바퀴 간격 조절.

  3. 부품 자리 잡기 (연결 없이 위치만)

    아래 배치도대로 마스킹테이프로 가고정만 합니다. 배선 길이가 닿는지 이 단계에서 가늠해보세요.

    ⚠ TB6612 모듈에 핀헤더(빗살 금속핀)가 납땜돼 있는지 확인 — 핀이 봉지에 따로 들어있으면 납땜이 필요한 타입입니다.

④ 첫 테스트는 반드시 차체 뒤집어 바퀴를 공중에 띄우고 — 데드맨이 검증되기 전까지 바닥 주행 금지.

04배선 순서 — 브레드보드 버전 (무납땜)

브레드보드 = 스테이징 환경. 납땜 없이 꽂았다 뺐다 하며 회로를 검증하는 판입니다. 안쪽 구멍은 세로 5칸씩 전기적으로 이어져 있고, 가장자리 빨강(＋)/파랑(−) 레일은 가로로 쭉 이어져 있어요. 이번 배선에선 빨강 레일 = 3.3V 버스, 파랑 레일 = GND 버스로 씁니다. TB6612를 빵판에 꽂는 순간 모터 전류도 어차피 접점을 지나므로, 모터·배터리선까지 전부 빵판에서 최종 탑재합니다. 연결 규칙은 하나: 같은 세로 5칸 줄 = 같은 노드. 예컨대 VM 핀 줄에 배터리＋와 SD-0516 IN+를 같이 꽂으면 셋이 이어져요. 접점 한계(~1A) 때문에 지킬 것은 스톨 금지뿐 — 트랙이 끼인 채 모터가 버티는 상황을 오래 두지 않기.
  1. 납땜 포인트 정리 (여기만 인두 등장)

    ① TB6612·C3 핀헤더가 따로 들어있으면 납땜 ② SD-0516 패드 4개(IN+/IN−에 배터리 쪽 전선, OUT+/OUT−에 빵판용 전선 또는 헤더핀) ③ 모터 전선 끝이 연선이라 안 꽂히면 끝만 살짝 납땜해 굳히기(또는 듀폰 수컷 압착). 이게 전부 — 나머지는 전부 꽂기.

  2. 벤치 준비

    TP101을 뒤집어 바퀴를 공중에 띄웁니다. 배터리는 홀더에서 빼둡니다. TB6612와 C3를 빵판 중앙 홈을 걸치게 꽂습니다.

  3. TB6612 로직 묶음 → 3.3V 레일

    C3의 3V3 핀을 빨강 레일에 꽂고, TB6612의 VCC·STBY·PWMA·PWMB 네 핀을 각각 빨강 레일로 연결합니다.

    왜? STBY(standby)가 LOW면 칩이 잠들고, PWMA/PWMB가 LOW면 출력이 차단돼요. 넷 다 HIGH 고정 = "칩 항상 깨움 + 출력 항상 허용". 속도는 AIN/BIN 핀의 PWM으로만 조절하는 단순화 전략입니다.

  4. 신호선 4가닥

    GPIO3→AIN1, GPIO4→AIN2 (왼쪽) / GPIO5→BIN1, GPIO6→BIN2 (오른쪽). 수-수 점퍼선으로.

  5. GND 공통 → 파랑 레일

    C3 GND와 TB6612 GND를 파랑 레일에 연결합니다. 두 회로가 섞이는 유일한 지점.

  6. 모터 연결

    왼쪽 모터 두 가닥을 A01/A02 핀이 꽂힌 세로줄에, 오른쪽을 B01/B02 줄에 꽂습니다. 극성은 아직 신경 쓰지 마세요 — 돌려보고 반대면 두 선을 맞바꾸면 끝. 전선은 케이블타이로 빵판에 묶어 진동 대비.

  7. 1차 테스트: USB 전원만으로

    배터리·SD-0516 없이 C3를 USB로 켜고 펌웨어 플래시 → Wi-Fi 접속 → 조종실 WS 연결까지 확인합니다. 모터는 아직 안 돕니다(VM 무전원) — 로직만 먼저 검증.

  8. 배터리 투입 (마지막!)

    배선 눈 점검 → 배터리 ＋와 SD-0516 IN+를 VM 핀이 꽂힌 세로줄에 같이 꽂기(빨강 레일 금지), 배터리 −와 SD IN− → 파랑 레일, SD-0516 OUT+ → C3 5V 핀 줄. 이때 USB는 반드시 뽑은 상태 — USB와 5V 핀 동시 연결 금지.

  9. 드라이브 테스트

    대시보드 WASD 패드 → 바퀴가 공중에서 도는지, 버튼을 떼면 300ms 안에 멈추는지(데드맨) 확인. 이게 통과해야 바닥 주행 허가입니다.

    운용 중 점검 신호: ① 주행 후 VM·모터 줄 근처 빵판이 따뜻하다 ② 한쪽 트랙만 가끔 멈춘다(접점 진동 불량) — 둘 중 하나가 보이면 그때 전류 경로만 듀폰 직결로 전환.

05전원 켜기 전 체크리스트

  • 빨간 선(7.4V)이 VM과 벅 컨버터 IN 외엔 아무 데도 안 닿는다
  • VCC·STBY·PWMA·PWMB 전부 3.3V에 묶였다
  • C3 GND ↔ TB6612 GND 연결됐다 (공통 기준선)
  • C3의 5V에 7.4V가 직결되지 않았다 (SD-0516 OUT+ 또는 USB 전원)
  • SD-0516 IN/OUT 방향이 맞다 (IN+ ← 배터리 ＋, OUT+ → C3 5V — 뒤집으면 C3 즉사)
  • 바퀴가 공중에 떠 있다
  • 18650이 2개다 (3개 아님)
  • USB 케이블과 SD-0516 OUT+가 동시에 연결돼 있지 않다
  • 빵판 빨강 레일에 7.4V가 꽂혀 있지 않다 (빨강 레일은 3.3V 전용 — 배터리＋는 레일을 거치지 않고 VM·SD-0516 IN+로 직행)

다음 단계: drive 펌웨어(capabilities에 "drive" 추가 + PWM 변환 + ttlMs 데드맨) — 서버·대시보드·프로토콜은 이미 준비돼 있습니다. 펌웨어 후속 과제: 배터리 전압을 분압해 ADC로 읽고 7.2V 이하에서 주행 정지 + LED 경고하는 저전압 컷오프 — SD-0516의 입력 하한(7V)에 닿기 전에 소프트웨어가 먼저 알립니다.
